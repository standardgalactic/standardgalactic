# Hollywood Terminal Simulator

A browser-based cinematic terminal simulator with animated pseudo-security output, matrix-style streams, and interactive command prompts.

## Included Commands

- `help`
- `status`
- `feed`
- `scan`
- `trace`
- `decrypt`
- `rig`
- `puzzle`
- `clear`
- `about`

All command output is fictional and intended for local-only terminal theater.

## Run

Open `experiments/terminal-simulator/index.html` in a browser.

No build step is required.
